# Legacy releases and tools

This directory preserves the original project files for reference. They are
not built, extracted, or executed by V4.

| Directory | Historical purpose |
|---|---|
| `V3/` | WPF front end and bundled Windows ISO/CHD helper tools |
| `GameName (game-id)/` | ISO variant that appended the game ID |
| `V2.5/` and `PS2-ISO-Batch-RenamerV2/` | Earlier handwritten ISO renamers |
| `ps2_chd_renamer/` | Earlier external CHD conversion/helper chain |
| `Failed Rename/` | Historical failed-rename notes |
| `PS2 - Game ID to Game Title/` | Historical spreadsheet helper |
| `screenshots/` | Screenshots from earlier workflows |

The current native implementation is under the repository root in `src/`.
Its parity notes are in [`../docs/algorithm.md`](../docs/algorithm.md).
